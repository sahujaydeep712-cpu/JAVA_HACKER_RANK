## 🚀 How to Run

### Requirements
- Java Development Kit (JDK 8 or later, e.g. JDK 17, 21+)

### Compile and Execute
Navigate to any problem directory and compile using `javac`:

```bash
cd 01-Introduction/01-Welcome-to-Java
javac Solution.java
java Solution
```

### Provide Input via Standard Input
For solutions requiring input, redirect standard input or pass via pipe:

```bash
java Solution < input.txt
```
